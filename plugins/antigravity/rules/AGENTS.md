# Aither World & awdk Rules (Google Antigravity)

- **Platform first — never hand-roll.** Use existing `aw*` lanes (`adk pack`, `awrise`, `awrun`, `awgit`, `awsettings`, `awkno`, `awrelay`, `awm`, `awsh`, `awfocus`, `awdecide`, `awask`, or MCP tools) before writing ad-hoc scripts or starting bare background processes.
- **Zero standalone installer or runner scripts (hard-enforced by PreToolUse hook).** Never create `scripts/*.sh`, `*install*.sh`, `*setup*.sh`, `*schedule*.sh`, or standalone `scripts/*.py` wrappers alongside an `adk` pack. Ship every capability as a native `adk` pack tool (`adk pack new/validate/dev/build/install/enable`) and schedule recurring jobs with `awrise add --executor agent --report-relay "#decisions" --card-after 1`.
- **Execute implied fixes — zero permission-begging.** When the owner asks a diagnostic or status question implying a desired state (*"are all X on Y?"*, *"is X updated?"*, *"where is Z?"*) and live inspection reveals a local, reversible gap (not B1/B2/B3), diagnose AND fix it immediately — report what was broken, what you already fixed, and live proof. Never stop at *"No, it's broken — say the word and I'll fix it."*
- **Check prior decisions before asking.** Before asking the owner any design, tooling, or preference question, search sibling session transcripts (`~/.gemini/antigravity/brain/`, `~/.claude/projects/`), `awm` / `recall`, and recent `git log` (24–48h) first. Never re-ask a decision the owner already made in another session.
- **Hard stop ONLY on real B1/B2/B3.** Pause for confirmation only on **B1** (physically impossible), **B2** (genuinely irreversible external action — public publish/deploy/spend/data deletion — not already authorized), or **B3** (owner already said no). Even then, stage and verify everything up to the trigger first.
- **Concurrent-safe git (`awgit`).** In shared repositories, acquire path leases (`awgit lease acquire <paths>`) and commit scoped paths (`awgit blob-commit`). Never run raw `git merge`, `git rebase`, `git pull`, `git stash`, `git clean`, bare `git reset`, or pathspec-less `git commit`.
- **Two-way delegation.** Use `awdk-local` (`awdelegate`) and `awdk-awsh` (`awsh`) MCP tools or the `aw` subagent to offload sub-tasks to local models (DeepSeek/vLLM/MicroScheduler) or peer harnesses (`awdk`, `codex`, `opencode`, `gemini`, `aither`).
- **Secrets.** Never echo tokens, API keys, or credentials into prose, logs, or commits.
