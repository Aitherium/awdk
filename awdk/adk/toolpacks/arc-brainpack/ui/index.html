How to contribute

  1. Enroll — call arc_register (mints an ACTA wallet, gets a contributor token, persists it). Or a maintainer adds you to contrib_tokens.json and you set WM_CONTRIB_TOKEN.
  2. Set ARC_API_KEY so you can reach the ARC game API.
  3. Contribute — call arc_contribute(games="ls20,vc33", n=200). It plays each game with a random policy and submits every transition (quarantined + vetted offline).
  4. Track — arc_status for your accept count, this panel for the ranking.
  5. Solo — prefer your own box? arc_solo prints the one-command docker-compose.standalone.yml bootstrap (world model + gateway, loopback-only, no GPU).
