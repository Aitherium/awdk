# AitherShell Bundled Binaries

This directory contains bundled AitherShell binaries for offline deployments.

## Directory Structure

- `win-x64/` — Windows x86-64 binaries
- `linux-x64/` — Linux x86-64 binaries
- `mac-arm64/` — macOS ARM64 (Apple Silicon) binaries
- `mac-x64/` — macOS x86-64 binaries

## Populating at Build Time

This directory is populated by the CI workflow (`.github/workflows/release-shell-cli.yml`)
when building a `shell-cli-v*` release tag. The CI process:

1. Builds platform-specific AitherShell binaries
2. Generates `checksums.sha256` over all binaries
3. **Copies binaries into respective platform directories here**
4. Publishes the full release to GitHub with both downloadable artifacts
   and bundled fallbacks embedded in the Python package

## Runtime Fallback

When `adk shell` runs and the cached binary is not found:

1. **Download from GitHub Releases** — Fetches the latest shell-cli-v* release
   and verifies SHA256 against `checksums.sha256`
2. **Use bundled binary** (this directory) — If download fails or network is
   unavailable, falls back to the bundled version that shipped with the
   awdk package

This ensures the product works offline after first install, and keeps users
on the latest version when network is available.

## Do NOT commit fake binaries

The actual binaries are generated by CI and added via the release workflow.
Do not check in placeholder or test binaries — the CI will populate these
directories on each release.

## GitHub Release Layout

On release, the GitHub Release contains:

```
Release: shell-cli-v1.2.3
├── aither-shell-win64.exe
├── aither-shell-linux-x64
├── aither-shell-macos-arm64
├── aither-shell-macos-x64
└── checksums.sha256
```

All are published as downloadable assets AND copied into the package
for offline fallback.
