Create your twin

A twin is your agent, running for you. Where its model runs decides what it costs. Only a twin hosted on Aitherium's own compute is counted or limited. Twins on your own key or your own hardware are not.

Aitherium's shared compute works

Your twin hosted by Aitherium on its own model. First twin free; each extra one is a one-time fee. A daily turn limit applies per twin. Only for agents Aitherium's twin server carries.

adk agent twin deploy --hosted
Start in Studio

Your own Anthropic key works

Your agent pack as a managed agent hosted at Anthropic, with tools, memory and approvals bridged back to AitherOS through the gateway. Anthropic bills you for use. Nothing to Aitherium. No Aitherium limit on number or turns.

adk agent managed byok, then adk agent twin deploy --anthropic

Your own key for another provider (for example DeepSeek) works

The kit's agent loop on your machine, using your provider key, with skills, tools, tool packs, agent packs and MCP. Your provider bills you for use. The agent loop runs on your machine; Aitherium hosting the loop on your non-Anthropic key is not built.

adk host --provider deepseek

A GPU rented in your own GPU-provider account quote only

A rented GPU running the twin's model, paid by you to the provider. About the cost of the rental; varies by model and GPU. The command quotes and rents nothing. A twin on Aitherium's twin server cannot use a rented GPU yet.

adk agent twin deploy --dedicated --dry-run

Your own hardware works

The twin's agent server on your own machine or node. Any number of twins. Free. No Aitherium limit on number or turns.

adk agent twin deploy
  • One twin on one machine works: adk agent twin deploy
  • Several machines of yours on one private mesh works: adk mesh join, then adk agent twin deploy --reach mesh
  • Agents on the mesh finding and calling each other works: adk agents ls; adk chat <agent>
  • A shared multi-user room with a workspace attached to that mesh not built. Workspaces and rooms exist as separate platform tools; nothing joins them to a mesh of twins.

The same list, live: adk agent twin doors
